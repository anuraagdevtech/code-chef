## Question

Everyone loves short problem statements.

Given a function $ f(x) $ find its minimum value over the range $ 0 \lt x \lt π/2$

$
f(x) = ( x^2 + b*x + c ) / sin( x )
$

**Input:**
- First-line will contain $T$, the number of test cases. Then the test cases follow.
- Each test case contains a single line of input, two real numbers $b, c$.

**Output:**
For each test case, output the minimum value of $ f(x) $ over the given range. Absolute error of $10^{-6}$ is allowed.

**Constraints**
- $1 \leq T \leq 100000$
- $1 \leq b,c \leq 20$

## Constraints

- $1 \leq T \leq 100000$
- $1 \leq b,c \leq 20$

## Sample

**Sample input**

```
1
2 2
```

**Sample output**

```
5.8831725615
```

## Approach

Differentiate the quotient: $f'(x)$ has the sign of

$$H(x) = (2x + b) \sin x - (x^2 + bx + c) \cos x.$$

$H$ is strictly increasing on $(0, \pi/2)$, because $H'(x) = (2 + x^2 + bx + c) \sin x > 0$. At $x \to 0$ it tends to $-c < 0$ and at $x = \pi/2$ it equals $\pi + b > 0$. So $H$ has exactly one root, $f$ decreases before it and increases after it, and the root is the global minimum.

Find the root by bisection on the sign of $H$ - 55 halvings are far below double precision on this interval - and evaluate $f$ there.

## Solution

```python
import sys
import sys, math


def main() -> None:
    tokens = iter(map(float, sys.stdin.buffer.read().split()))
    t = int(next(tokens))
    out = []
    for _ in range(t):
        b = next(tokens)
        c = next(tokens)
        low = 0.0
        high = math.pi / 2
        for _ in range(55):
            x = (low + high) / 2
            if (2 * x + b) * math.sin(x) - (x * x + b * x + c) * math.cos(x) < 0:
                low = x
            else:
                high = x
        x = (low + high) / 2
        out.append(f'{(x * x + b * x + c) / math.sin(x):.10f}')
    print('\n'.join(out))


if __name__ == "__main__":
    main()
```

## Edge cases

- $f$ blows up near 0, so the minimum is in the interior and bisection never evaluates $f$ at 0.
- $b$ and $c$ are real numbers in the input and are parsed as floats.
- The answer is printed with 10 decimals; an absolute error of $10^{-6}$ is allowed.
- Ternary search on $f$ would work too, but bisection on $H$ has a sharper stopping guarantee.

## Dry run

`b = 2, c = 2`. $H(0) = -2 < 0$ and $H(\pi/2) = \pi + 2 > 0$.

Bisection narrows the root of $H$ to $x \approx 0.878$, where $f(x) = (x^2 + 2x + 2) / \sin x \approx 5.8831725615$.
