# 383. Treasure Hunting

> [`N1`](https://www.codechef.com/problems/N1) &middot; difficulty **1634** &middot; time limit **1s** &middot; Rise from 3* to 4* (Level 4)

## Topic used

| | |
|---|---|
| **Topic** | Dynamic Programming |
| **Technique** | BFS distances between treasures and subset tour DP |
| **Complexity class** | Exponential subset DP $O(2^K K^2)$ |
| **Time** | $O((K+2)N^2+2^K K^2)$ per test case for $K$ treasures |
| **Space** | $O(N^2+2^K K)$ |

## Question

Treasure Hunting is a great computer game that has attracted generations of Bytelandian children.
In the game, there is a maze divided into $N \times N$ squares.

- Dave starts in the top-left corner, which is square $(1,1)$, and needs to go to the bottom-right corner, which is square $(N,N)$.
- Some of the squares are blocked and some of the squares contain treasures.
- Dave needs to capture all the treasures in the maze before going to square $(N,N)$.
- In each second, Dave can go to one of its four adjacent squares (if the destination is not blocked).

Find the earliest time that Dave can reach the destination $(N,N)$ after collecting all the treasures in the maze.

**Input**

- The first line contains $T$, the number of test cases. Then $T$ test cases follow.
- The first line of each testcase contains $N$, the size of the maze
- The $N$ following lines describe the maze. The meaning of the symbols is as follows:
   - '.' : an empty square
   - '*' : a treasure
   - '#' : a blocked square

**Output**

For each test case, print in a single line the earliest time that Dave can reach the destination after collecting all the treasures. If Dave cannot reach the destination, print -1.

## Constraints

- $1 \leq T \leq 15$
- $1 \leq N \leq 13$
- The number of treasures in the maze does not exceed 13.
- Squares $(1,1)$ and $(N,N)$ are always empty.

## Sample

**Sample input**

```
4

3
...
.##
*#.

3
..*
...
...

3
..*
*..
...

4
....
.#.*
.#*.
**#.
```

**Sample output**

```
-1
4
6
16
```

## Approach

Only the order of visiting treasures matters. BFS from the start, each treasure, and the finish yields shortest distances between these special cells. If any treasure or the finish is unreachable from the start, no valid route exists.

For nonempty treasure subset $mask$, let $dp[mask][j]$ be the least travel time starting at the entrance, visiting the treasures in $mask$, and ending at treasure $j$. Extend to each unvisited treasure using the precomputed distances. Once all treasures are included, add the distance to the exit and take the minimum. A shortest segment may pass through additional treasures, which never invalidates a route; the metric tour optimum still equals the shortest walk collecting everything.

## Solution

```python
import sys
from collections import deque


def main() -> None:
    tokens = iter(sys.stdin.buffer.read().split())
    out = []
    for _ in range(int(next(tokens))):
        n = int(next(tokens))
        grid = [next(tokens) for _ in range(n)]
        treasures = [r*n+c for r in range(n) for c in range(n) if grid[r][c] == 42]
        points = [0]+treasures+[n*n-1]
        k = len(treasures)
        distances = []
        for start in points:
            distance = [-1]*(n*n)
            distance[start] = 0
            queue = deque([start])
            while queue:
                u = queue.popleft()
                r,c = divmod(u,n)
                for v in (u-n if r else -1,u+n if r+1 < n else -1,
                          u-1 if c else -1,u+1 if c+1 < n else -1):
                    if v >= 0 and distance[v] == -1 and grid[v//n][v%n] != 35:
                        distance[v] = distance[u]+1
                        queue.append(v)
            distances.append([distance[v] for v in points])
        if any(d < 0 for d in distances[0]):
            out.append('-1')
            continue
        if k == 0:
            out.append(str(distances[0][-1]))
            continue
        infinity = 10**9
        dp = [[infinity]*k for _ in range(1 << k)]
        for j in range(k):
            dp[1 << j][j] = distances[0][j+1]
        full = (1 << k)-1
        for mask in range(1,full+1):
            for j in range(k):
                current = dp[mask][j]
                if current == infinity:
                    continue
                todo = full^mask
                while todo:
                    bit = todo&-todo
                    v = bit.bit_length()-1
                    target = mask|bit
                    dp[target][v] = min(dp[target][v],current+distances[j+1][v+1])
                    todo -= bit
        out.append(str(min(dp[full][j]+distances[j+1][-1] for j in range(k))))
    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    main()
```

## Edge cases

- With no treasures, return the ordinary start-to-finish shortest distance.
- The start and finish are guaranteed empty.
- Paths may revisit cells.
- A treasure unreachable from the start makes the answer minus one.
