## Question

You are given an array $A$ containing $N$ integers. Find if it is possible to choose **exactly** $M$ elements from the array such that the **MEX** of the chosen elements is **exactly** $K$.

Recall that the *MEX* of an array is the smallest non-negative integer that does not belong to the array. For example, the *MEX* of $[2, 2, 1]$ is $0$ because $0$ does not belong to the array, the *MEX* of $[3, 1, 0, 1]$ is $2$ because $0$ and $1$ belong to the array, but $2$ does not.

**Input**

- The first line contains an integer $T$, denoting the number of test cases. The $T$ test cases then follow:
- The first line of each test case contains an integer $N, M, K$, denoting the length of the array, the number of elements to be chosen, and the required MEX respectively.
- The second line of each test case contains $N$ space-separated integers $A_1,A_2,\ldots,A_N$, denoting the elements of the array.

**Output**

For each test case, print `YES` if it is possible to choose $M$ elements from the array $A$ so that the MEX of the chosen elements is exactly $K$ and `NO` otherwise.

You may print each character of the string in uppercase or lowercase (for example, the strings `yEs`, `yes`, `Yes` and `YES` will all be treated as identical).

## Constraints

- $1 \leq T \leq 100$
- $1 \leq N \leq 100$
- $1 \leq M \leq N$
- $0 \leq A_i, K \leq N$

**Subtasks**

- 30 points : $1 \leq R \leq 10000$
- 70 points : $1 \leq R \leq 10^9$

## Approach

"MEX exactly $K$" is two requirements pulling in opposite directions, and separating them makes the problem a plain interval test.

**Must include** every one of $0, 1, \ldots, K-1$ at least once — so each must be present in $A$ at all, and the chosen set needs at least $K$ elements. **Must exclude** $K$ entirely, so every occurrence of $K$ in $A$ is off limits, leaving $N - \mathrm{cnt}(K)$ usable elements.

Nothing else constrains the choice: values above $K$, and extra copies of values below $K$, are all **free padding** that cannot change the MEX. So any count between the floor and the ceiling is achievable, and the answer is `YES` exactly when

$$\{0, \ldots, K-1\} \subseteq A \quad\text{and}\quad K \leq M \leq N - \mathrm{cnt}(K)$$

The sample is built to fail each clause in turn. Case 2 ($M = 1 < K = 2$) has both $0$ and $1$ available but too few picks to include them. Case 4 needs $0, 1, 2$ but the array has no $1$ at all. Case 5 has $M = 4$ while only $5 - 2 = 3$ elements avoid $K = 2$ — the exclusion is what runs out. Case 6 is the same shape but with one fewer $2$, so $5 \leq 5$ just fits.

Case 3 is the tight corner: $K = M = N = 3$ with $A = [0,1,2]$, so every element is needed and the MEX is $3$ exactly. That is also why the ceiling is $N - \mathrm{cnt}(K)$ rather than $N$: here $\mathrm{cnt}(3) = 0$, so nothing is lost.

The case $K = 0$ falls out of the same formula — no values are required, only that enough elements avoid $0$.

## Solution (Python)

```python
import sys
from collections import Counter


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n, m, k = int(data[pos]), int(data[pos + 1]), int(data[pos + 2])
        counts = Counter(int(x) for x in data[pos + 3:pos + 3 + n])
        pos += 3 + n
        # Everything below K is mandatory; every copy of K is unusable; the
        # rest is free padding.
        ok = all(counts[v] for v in range(k)) and k <= m <= n - counts[k]
        out.append("YES" if ok else "NO")
    sys.stdout.write("\n".join(out) + "\n")


main()
```
