# 508. Total Diamonds

> [`VK18`](https://www.codechef.com/problems/VK18) &middot; difficulty **1786** &middot; time limit **1s** &middot; Rise from 3* to 4* (Level 4)

## Topic used

| | |
|---|---|
| **Topic** | Prefix Sums |
| **Technique** | Grow the square using a prefix sum of digit imbalances |
| **Complexity class** | Linear $O(n)$ |
| **Time** | $O(V+T)$ overall for $V=\max N$ |
| **Space** | $O(V+T)$ |

## Question

Chef is so good at programming that he won almost all competitions. With all the prizes, Chef bought a new house. The house looks like a grid of size **N** (1-indexed) which consists of **N** × **N** rooms containing diamonds. For each room, the room number is equal to the sum of the row number and the column number.

The number of diamonds present in each room is equal to the absolute difference between the sum of even digits and sum of odd digits in its room number. For example, if the room number is 3216, then the number of diamonds present in that room will be |(2+6)-(3+1)| = 4.

You are given the number **N**. You have to print the total number of diamonds present in Chef's house.

**Input**

- The first line of the input contains a single integer **T** denoting the number of test cases. The description of **T** test cases follows.

- The only line of each test case contains a single integer **N**.

**Output**

For each test case, print the answer on a separate line.

**Constraints**

- 1 ≤ **T** ≤ 10^5

- 1 ≤ **N** ≤ 10^6

**Subtasks**

**Subtask #1 (15 points):**

- 1 ≤ **T** ≤ 10

- 1 ≤ **N** ≤ 1000

**Subtask #2 (15 points):**

- 1 ≤ **T** ≤ 10

- 1 ≤ **N** ≤ 10^6

**Subtask #3 (70 points):** original constraints

<details><summary>Explanation</summary>

**Example case 3:** There are 9 rooms. Room (1,1) has number 2, room (1,2) has number 3, etc. For each room, the number of diamonds in it is equal to the room number, so the total number of diamonds present is (2+3+4+3+4+5+4+5+6) = 36.

</details>

## Approach

Let $d(s)$ be the absolute difference between even-digit and odd-digit sums of room number $s$. Compute signed digit balances from the balance of `s//10` plus the signed last digit, then prefix-sum their absolute values.

Growing an $(n-1)$-square to an $n$-square adds its last row and last column. Numbers $n+1$ through $2n-1$ appear twice, while $2n$ appears once. With digit-value prefix sums $P$, the increment is $P[2n]+P[2n-1]-2P[n]$. Precompute all square totals once, using compact numeric arrays and 64-bit totals.

## Solution

```python
import sys
from array import array


def main() -> None:
    values = list(map(int,sys.stdin.buffer.read().split()))
    limit = max(values[1:])
    balance = array('b',[0])*(2*limit+1)
    prefix = array('q',[0])*(2*limit+1)
    for s in range(1,2*limit+1):
        digit = s%10
        balance[s] = balance[s//10]+(digit if digit%2 == 0 else -digit)
        prefix[s] = prefix[s-1]+abs(balance[s])
    answer = array('q',[0])*(limit+1)
    for n in range(1,limit+1):
        answer[n] = answer[n-1]+prefix[2*n]+prefix[2*n-1]-2*prefix[n]
    sys.stdout.write('\n'.join(str(answer[n]) for n in values[1:])+'\n')

if __name__ == '__main__':
    main()
```

## Edge cases

- Room coordinates are one-based, so the first room number is two.
- Count the bottom-right corner once.
- Use absolute digit balance after summing all digits.
- Large square totals exceed 32 bits.

## Dry run

For `n=2`, the new cells have room numbers 3, 3, and 4, contributing ten diamonds. Add the first square value two to get twelve.
