# 594. Tetris

> [`SPCP6`](https://www.codechef.com/problems/SPCP6) &middot; difficulty **2062** &middot; time limit **1s** &middot; 2000 to 2500 difficulty problems (Level 5)

## Topic used

| | |
|---|---|
| **Topic** | Dynamic Programming |
| **Technique** | Ways by lines cleared and whose turn it is |
| **CodeChef tags** | `dynamic-programming` |
| **Complexity class** | Linear $O(n)$ |
| **Time** | $O(\max L + T)$ |
| **Space** | $O(\max L)$ |

## Question

Chef and Chefina are playing a game of Tetris together. In a single move, a player can either clear $1$, $2$, $3$, or $4$ lines of blocks. Clearing $4$ lines in a single move is called getting a "Tetris".

Chef and Chefina take turns playing, with Chef starting first.
Whenever the current player clears only one line, the turn shifts to the other player; otherwise it remains with the current player.
They will stop playing as soon as **at least** $L$ lines are cleared in total. That is, the game stops when the sum of the number of lines cleared by both the players is at least $L$.

Chef wants to end the game in style, and so would like to be the one who finishes the game *and* do so by getting a "Tetris", i.e, by clearing $4$ lines.
How many sequences of moves are there in which this happens?

The number of sequences may be large, so print it modulo $10^9 + 7$.

**Input**

- The first line of input will contain a single integer $T$, denoting the number of test cases.
- Each of the next $T$ lines contains one integer $L$ — the number of lines to be cleared.

**Output**

- For each test case, output on a new line the total number of ways in which Chef can finish the game by getting a "Tetris", modulo $10^9+7$.

## Constraints

- $1 \leq T \leq 10^5$
- $1 \leq L \leq 10^5$

**Subtasks**

- **Subtask 1 (10 points):** $1 \leq M \leq 10$
- **Subtask 2 (20 points):** The sum of $N$ across all test cases won't exceed $20$.
- **Subtask 3 (70 points):** No further constraints.

## Sample

**Sample input**

```
4
3
2
4
100000
```

**Sample output**

```
3
1
4
246691813
```

<details><summary>Explanation</summary>

**Test case $1$:** For $L=3$, there are $3$ possible ways such that Chef can finish the game with a "Tetris":
- Clear $4$ lines immediately.
- Clear $2$ lines first, then $4$.
- Clear one line, transferring the turn to Chefina. Chefina then clears one line, transferring the turn back to Chef, who then gets a "Tetris".

**Test case $2$:** For $L = 2$, the only possibility is that Chef gets a "Tetris" on the very first move.

**Test case $3$:** For $L = 4$, there are $4$ valid sequences of moves: $(2,4), (1,1,4), (3,4), (4)$.

</details>

## Approach

Let `chef[i]` be the number of move sequences after which exactly $i$ lines are cleared and it is Chef's turn, and `chefina[i]` the same with Chefina to move. A move of 1 line passes the turn; moves of 2, 3 or 4 lines keep it:

$$\text{chef}[i] = \text{chefina}[i-1] + \text{chef}[i-2] + \text{chef}[i-3] + \text{chef}[i-4],$$

and symmetrically for Chefina, with `chef[0] = 1`.

The game ends as soon as the total reaches $L$, and Chef must end it with a 4-line move. So the game is at some total $i < L$ with Chef to move and $i + 4 \ge L$: the answer is $\text{chef}[L-4] + \dots + \text{chef}[L-1]$ (indices below 0 skipped). States with $i < L$ are exactly the unfinished games, so nothing is counted after the end.

All queries share one table built up to the largest $L$.

## Solution

```python
import sys


def main() -> None:
    tokens = iter(map(int, sys.stdin.buffer.read().split()))
    out = []
    queries = [next(tokens) for _ in range(next(tokens))]
    limit = max(queries)
    MOD = 10 ** 9 + 7
    chef = [0] * (limit + 1)
    chefina = [0] * (limit + 1)
    chef[0] = 1
    for i in range(1, limit + 1):
        chef[i] = (chefina[i - 1] + sum(chef[max(0, i - 4):max(0, i - 1)])) % MOD
        chefina[i] = (chef[i - 1] + sum(chefina[max(0, i - 4):max(0, i - 1)])) % MOD
    for lines in queries:
        out.append(str(sum(chef[max(0, lines - 4):lines]) % MOD))
    print('\n'.join(out))


if __name__ == "__main__":
    main()
```

## Edge cases

- For $L \le 4$ the window is cut off at 0 and includes the empty game (an immediate Tetris).
- The finishing move must be exactly a 4, even when fewer lines would be enough to reach $L$.
- A 1-line move changes the player; this is the only link between the two arrays.
- Results are modulo $10^9 + 7$.

## Dry run

`L = 3`.

`chef[0] = 1`; `chefina[1] = chef[0] = 1`, `chef[1] = chefina[0] = 0`; `chef[2] = chefina[1] + chef[0] = 2`.

Answer `chef[0] + chef[1] + chef[2] = 3`: a Tetris at once; 2 lines then a Tetris; or 1 line, Chefina clears 1 line, then a Tetris.
