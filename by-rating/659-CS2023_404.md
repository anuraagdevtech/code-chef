# 659. Search for 404

> [`CS2023_404`](https://www.codechef.com/problems/CS2023_404) &middot; difficulty **2296** &middot; time limit **1s** &middot; 2000 to 2500 difficulty problems (Level 5)

## Topic used

| | |
|---|---|
| **Topic** | Dynamic Programming |
| **Technique** | Subsequence-counting DP summed over all replacements |
| **CodeChef tags** | `Mathematics`, `Combinatorics`, `Permutations & Combinations` |
| **Complexity class** | Linear $O(n)$ |
| **Time** | $O(N)$ per test case |
| **Space** | $O(1)$ |

## Question

Om has a string $S$ consisting of characters $*$, $4$, and $0$ only.
- The character $*$ can be replaced by either $4$ or $0$.

Om wants to count the total number of [subsequences](https://en.wikipedia.org/wiki/Subsequence) of $404$ present in all the possible strings generated after replacing $*$.
As the number can be huge, you must output the number modulo $10^{9}+7$.

For example, if the given string is $S =$ $4*4*$, the possible strings after replacing $*$ are:
- $4040$: Only one subsequence of $404$ is present, that is $S_1S_2S_3$.
- $4044$: Two subsequences of $404$ are present, that are $S_1S_2S_3$ and $S_1S_2S_4$.
- $4440$: No subsequence of $404$ is present.
- $4444$: No subsequence of $404$ is present.

Thus, total number of $404$ subsequences present in all possible generated strings is $3$.

**Input**

- The first line of input will contain a single integer $T$, denoting the number of test cases.
- Each test case consists of multiple lines of input.
    - The first line of each test case contains an integer $N$ — size of the given string.
    - The second line has a string $S$ of size $N$.

**Output**

For each test case, output the total number of subsequences of $404$ present in all the possible strings generated after replacing $*$.
As the number can be huge, you must output the number modulo $10^{9}+7$.

## Constraints

- $1 \leq T \leq 10^{5}$
- $1 \leq N \leq 10^{5}$
- $S$ consists of $*, 4,$ and $0$ only.
- The sum of $N$ over all test cases won't exceed $10^{6}$.

## Sample

**Sample input**

```
2
4
4*04
4
4*4*
```

**Sample output**

```
4
3
```

<details><summary>Explanation</summary>

**Test case $1$:** All possible generated strings of $4*04$ are:
- $4004$: Two subsequences of $404$ are present, that are $S_1S_2S_4$ and $S_1S_3S_4$.
- $4404$: Two subsequences of $404$ are present, that are $S_1S_3S_4$ and $S_2S_3S_4$.

Thus, the total number of $404$ subsequences present in all possible generated strings is $4$.

**Test case $2$:** Already explained in problem statement.

</details>

## Approach

Count, over all strings generated so far, the total number of subsequences equal to `4`, `40` and `404`, together with the number of generated strings.

- A literal `4` can start a new subsequence in every string (`count_4 += strings`) and can finish any `40` (`count_404 += count_40`).
- A literal `0` extends every `4` to `40` (`count_40 += count_4`).
- A `*` splits every string into two. Every existing subsequence survives in both copies, so all counts double; in addition the copy where it becomes `4` gets the contributions of a literal `4`, and the copy where it becomes `0` those of a literal `0`:

$$\text{strings}' = 2\,\text{strings},\quad c_4' = 2 c_4 + \text{strings},\quad c_{40}' = 2 c_{40} + c_4,\quad c_{404}' = 2 c_{404} + c_{40}.$$

All four updates use the old values. The answer is the final `count_404`.

## Solution

```python
import sys


def solve(tokens):
    int(next(tokens))
    text = next(tokens)
    MOD = 1000000007
    strings = 1
    count_4 = count_40 = count_404 = 0
    for char in text:
        if char == 52:
            count_4 = (count_4 + strings) % MOD
            count_404 = (count_404 + count_40) % MOD
        elif char == 48:
            count_40 = (count_40 + count_4) % MOD
        else:
            strings, count_4, count_40, count_404 = (2 * strings % MOD, (2 * count_4 + strings) % MOD, (2 * count_40 + count_4) % MOD, (2 * count_404 + count_40) % MOD)
    return str(count_404)


if __name__ == "__main__":
    tokens = iter(sys.stdin.buffer.read().split())
    t = int(next(tokens))
    out = [solve(tokens) for _ in range(t)]
    sys.stdout.write('\n'.join(out))
```

## Edge cases

- No `*` at all: the plain count of `404` subsequences.
- The updates for `*` must be simultaneous, hence the tuple assignment.
- For a literal `4`, `count_404` uses `count_40` which that character does not change, so the order of the two updates is irrelevant.
- Everything is modulo $10^9 + 7$.

## Dry run

`S = 4*4*`, state (strings, `4`, `40`, `404`):

- start: (1, 0, 0, 0)
- `4`: (1, 1, 0, 0)
- `*`: (2, 3, 1, 0)
- `4`: (2, 5, 1, 1)
- `*`: (4, 12, 7, 3)

Answer 3.
