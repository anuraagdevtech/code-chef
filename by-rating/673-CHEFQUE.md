# 673. Chef and Queries

> [`CHEFQUE`](https://www.codechef.com/problems/CHEFQUE) &middot; difficulty **2327** &middot; time limit **2s** &middot; 2000 to 2500 difficulty problems (Level 5)

## Topic used

| | |
|---|---|
| **Topic** | Bit Manipulation |
| **Technique** | A packed bitmap as the set, with an incrementally maintained sum |
| **CodeChef tags** | `Mathematics`, `Bit Manipulation`, `Algorithms`, `Bitmasking`, `Bitwise Operation`, `Hashing` |
| **Complexity class** | Linear $O(n)$ |
| **Time** | $O(Q)$ |

## Question

As part of his daily job, Chef has to solve problems involving sets. Till now, Chef has been using inefficient methods to solve his set related problem, wasting a lot of his precious time. He has agreed to pay you a lot of money for solving the following problem for him efficiently.

First, Chef needs to perform **Q** operations on a set. Each operation is either:

- 1. Add a number to the set (if this number is NOT already present in the set).

- 2. Erase a number from the set (if this number exists in the set).

Then, he needs to find the sum of all elements of the set after performing these **Q** queries. Your job is to find this sum for him quickly.

**Input**

The first line of input contains four integers — **Q**, **S_1**, **A**, **B**. **S_1** is the first number in the operations. **A** and **B** are special constants explained later.

Every operation **S_i** is represented by a single integer. If **S_i** is odd, then it represents the first operation, otherwise the second type, and in both of them the integer you have to add/delete equals [**S_i** / 2], where [] is the greatest integer (or floor) function.

**S_i** = (**A*****S_i-1** + **B**) mod **2^32** when **i** > 1.

**Note:** In this problem, the time limit is very tight. Using built-in data structures, such as set/unordered_set in C++ or TreeSet/HashSet in Java, may lead to a Time Limit Exceed verdict.

**Output**

Output a single line containing a single integer — sum of elements in the set after **Q** queries.

**Constraints**

- 1 ≤ **Q** ≤ 10^7

- 1 ≤ **S_1, A, B** ≤ 109

**Example**

```
**Input:**
<tt>5 1 1 1
</tt>
**Output:**
<tt>3
</tt>

**Input:**
<tt>10000000 777777777 777777777 777777777
</tt>
**Output:**
<tt>5362358669068782</tt>
```

**Explanation:**

The sequence {S_i} is 1, 2, 3, 4, 5:

Operation 1, 1 mod 2 = 1, add number [1 / 2] = 0 to set, sum is 0.

Operation 2, 2 mod 2 = 0, erase number [2 / 2] = 1 from set, 1 is not in set, so nothing happens, sum is 0.

Operation 3, 3 mod 2 = 1, add number [3 / 2] = 1 to set, sum is 1.

Operation 4, 4 mod 2 = 0, erase number [4 / 2] = 2 from set, 2 is not in set, so nothing happens, sum is 1.

Operation 5, 5 mod 2 = 1, add number [5 / 2] = 2 to set, sum is 3.

## Constraints

- 1 ≤ Q ≤ 10^7
- 1 ≤ S_1, A, B ≤ 109

## Approach

The operations are generated by $S_{i+1} = (A \cdot S_i + B) \bmod 2^{32}$: the number concerned is $\lfloor S_i / 2 \rfloor$, and the lowest bit of $S_i$ says whether to add it (odd) or erase it (even). Only the final sum of the set is printed.

With millions of operations a hash set is too slow and too large, but the numbers are below $2^{31}$, so membership fits into a bitmap of $2^{31}$ bits = $2^{28}$ bytes. For every operation locate the byte and the bit, test it, and

- on "add", if the bit is clear: set it and add the number to the running sum;
- on "erase", if the bit is set: clear it and subtract the number.

Operations that do not change the set do not touch the sum. The generator step uses a bit mask for the reduction modulo $2^{32}$.

## Solution

```python
import sys


def main():
    operations, state, mul, add = map(int, sys.stdin.buffer.read().split())
    bits = bytearray(1 << 28)
    total = 0
    for _ in range(operations):
        number = state >> 1
        byte = number >> 3
        mask = 1 << (number & 7)
        present = bits[byte] & mask
        if state & 1:
            if not present:
                bits[byte] |= mask
                total += number
        elif present:
            bits[byte] ^= mask
            total -= number
        state = mul * state + add & 4294967295
    print(total)


if __name__ == "__main__":
    main()
```

## Edge cases

- Adding a number that is already present, or erasing an absent one, has no effect.
- The number 0 can be in the set; it changes membership but not the sum.
- The sum is far beyond 32 bits.
- The bitmap is allocated once and takes 256 MB.

## Dry run

`Q = 5, S_1 = 1, A = 1, B = 1`: the states are `1, 2, 3, 4, 5`.

| state | number | action | set | sum |
|---:|---:|---|---|---:|
| 1 | 0 | add | {0} | 0 |
| 2 | 1 | erase (absent) | {0} | 0 |
| 3 | 1 | add | {0, 1} | 1 |
| 4 | 2 | erase (absent) | {0, 1} | 1 |
| 5 | 2 | add | {0, 1, 2} | 3 |

Answer 3.
