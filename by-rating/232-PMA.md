## Question

Chef has an array $A$ of length $N$. He defines the *alternating sum* of the array as:
- $S = |A_1| - |A_2| + |A_3| - |A_4| + \ldots (-1)^{N-1}\cdot |A_N|$

Chef is allowed to perform the following operation on the array **at most once**:
- Choose two indices $i$ and $j$ $(1 \leq i <  j \leq N)$ and swap the elements $A_i$ and $A_j$.

Find the **maximum** *alternating sum* Chef can achieve by performing the operation **at most once**.

**Note:** $|X|$ denotes the absolute value of $X$. For example, $|-4| = 4$ and $|7| = 7$.

**Input**

- The first line will contain $T$ - the number of test cases. Then the test cases follow.
- First line of each test case contains a single integer $N$ - size of the array $A$.
- Second line of each test case contains $N$ space separated integers - denoting the elements of array $A$.

**Output**

For each testcase, output in a single line, the **maximum** *alternating sum* Chef can obtain by performing the operation **at most once**.

## Constraints

- $1 \leq T \leq 10^5$
- $2 \leq N \leq 10^5$
- $-10^9 \leq A_i \leq 10^9$
- Sum of $N$ over all test cases does not exceed $2 \cdot 10^5$.

**Subtasks**

- 30 points : $1 \leq R \leq 10000$
- 70 points : $1 \leq R \leq 10^9$

## Sample

**Sample input**

```
2
2
10 -10
7
-3 -2 -1 0 1 2 3
```

**Sample output**

```
0
6
```

<details><summary>Explanation</summary>

**Test Case $1$:** One optimal way is to perform no operations. Thus the alternating sum is $|10| - |-10| = 10 - 10 = 0$.

**Test Case $2$:** One optimal way is to choose $i = 2$ and $j = 5$. After swapping, the array is $[-3, 1, -1, 0, -2, 2, 3]$. The alternating sum in this case is $|-3| - |1| + |-1| - |0| + |-2| - |2| + |3| = 6$.

</details>

## Approach

Only the **absolute values** enter the sum, so write $b_i = |A_i|$. Odd positions contribute $+b_i$ and even positions $-b_i$.

A swap exchanges the values at two positions. Swapping two positions of the same sign changes nothing — the same two numbers are added and subtracted either way. So the only useful move trades a plus-position value $p$ for a minus-position value $m$, changing the total by

$$(m - p) - (p - m) = 2(m - p)$$

To maximise that, take the **largest** magnitude sitting on a minus position and the **smallest** magnitude sitting on a plus position. The operation is optional, so if that gain is negative it is simply declined — hence the clamp at zero.

Everything is one pass: accumulate the alternating sum while tracking the minimum $b$ over odd positions and the maximum $b$ over even positions.

Sample case 1 is the no-gain case: $[10, -10]$ has magnitudes $10$ and $10$, so the sum is $0$ and swapping changes nothing. Sample case 2 starts at $3 - 2 + 1 - 0 + 1 - 2 + 3 = 4$; the smallest plus magnitude is $1$ and the largest minus magnitude is $2$, so the swap adds $2(2-1) = 2$, giving $6$.

The absolute values are what make the sign of $A_i$ irrelevant — a detail worth checking early, since $A_i$ may be negative and the naive alternating sum of the raw values is a different quantity entirely.

## Solution

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos])
        vals = data[pos + 1:pos + 1 + n]
        pos += 1 + n
        total = 0
        min_plus = None       # smallest magnitude on an added position
        max_minus = None      # largest magnitude on a subtracted position
        for i, v in enumerate(vals):
            b = abs(int(v))
            if i % 2 == 0:
                total += b
                if min_plus is None or b < min_plus:
                    min_plus = b
            else:
                total -= b
                if max_minus is None or b > max_minus:
                    max_minus = b
        gain = 0
        if max_minus is not None:
            # The swap is optional, so never take a negative gain.
            gain = max(0, 2 * (max_minus - min_plus))
        out.append(str(total + gain))
    sys.stdout.write("\n".join(out) + "\n")


main()
```
