## Question

Given an array $A$ of size $N$, construct an array $B$ of size $N$ such that :
- Every element of $B$ is present **at least once** in $A$;
- For all $1\le i \le N$, every element in prefix $[A_1,A_2, \ldots, A_i]$ is present **at least once** in prefix $[B_1,B_2,\ldots, B_i]$.

If multiple such arrays $B$ exist, find the **lexicographically largest** $B$.

Note that for two arrays $X$ and $Y$, each of size $N$, where $i$ is the smallest index at which they differ, array $X$ is said to be lexicographically larger than array $Y$ when $X_i \gt Y_i$.

**Input**

- The first line of input will contain a single integer $T$, denoting the number of test cases.
- Each test case consists of two lines of input.
    - The first line of each test case contains a single integer $N$ — the number of elements in the array.
    - The second line of each test case contains $N$ space-separated integers $A_1,A_2,\ldots ,A_N$ — the elements of the array.

**Output**

For each test case, output on a new line, lexicographically largest array $B$ satisfying the conditions.

It can be guaranteed that one such array $B$ always exists.

## Constraints

- $1 \leq T \leq 10^5$
- $1 \leq N \leq 10^5$
- $1 \leq A_i\leq 10^5$
- The sum of $N$ over all test cases won't exceed $5\cdot 10^5$.

## Sample

**Sample input**

```
3
4
5 5 2 3
2
8 9
3
7 1 7
```

**Sample output**

```
5 5 2 3 
8 9 
7 1 7
```

<details><summary>Explanation</summary>

**Test case $1$:** Consider $B = [5, 5, 2, 3]$. Every element of $B$ is present **at least once** in $A$.
- $i=1$: Prefix of $A$ is $[5]$ and $B$ is $[5]$. Every element in prefix of $A$ is present in prefix of $B$ at least once.
- $i=2$: Prefix of $A$ is $[5,5]$ and $B$ is $[5,5]$.
- $i=3$: Prefix of $A$ is $[5,5,2]$ and $B$ is $[5,5,2]$.
- $i=4$: Prefix of $A$ is $[5,5,2,3]$ and $B$ is $[5,5,2,3]$.

Also, this is the lexicographically largest possible $B$.

**Test case $2$:** Consider $B = [8, 9]$. Every element of $B$ is present **at least once** in $A$.
- $i=1$: Prefix of $A$ is $[8]$ and $B$ is $[8]$.
- $i=2$: Prefix of $A$ is $[8,9]$ and $B$ is $[8,9]$.

Also, this is the lexicographically largest possible $B$.

**Test case $3$:** It can be proved that this is the lexicographically largest possible $B$.

</details>

## Approach

Walk left to right and ask at each position whether $B_i$ is forced.

The prefix condition at $i$ requires every distinct value of $A_1 \ldots A_i$ to have appeared in $B_1 \ldots B_i$. Inductively $B_1 \ldots B_{i-1}$ already covers $A_1 \ldots A_{i-1}$, so the only possible gap is $A_i$ itself, and only when $A_i$ has not appeared in $B$ yet. In that case $B_i = A_i$ is forced. Otherwise $B_i$ is **free**, and since every element of $B$ must occur somewhere in $A$, the largest legal choice is $\max A$.

$$B_i = \begin{cases} A_i & A_i \notin \{B_1, \ldots, B_{i-1}\} \\ \max A & \text{otherwise}\end{cases}$$

Filling free slots with $\max A$ is safe as well as locally greedy: it only *adds* to the set of values already present in $B$, which can never turn a later free slot into a forced one. So the greedy choice never costs anything downstream, and taking the largest value at the earliest differing position settles the lexicographic comparison.

Note the test is against the values already in $B$, not against those seen in $A$. The two differ exactly when a free slot has already deposited $\max A$ before $\max A$'s own first appearance in $A$ — and then that appearance is free too.

In all three samples $B$ coincides with $A$, because no free slot arises before each new value. The mechanism shows up on an input like $A = [1,1,2]$, where the repeated $1$ frees position $2$ for a $2$, which in turn frees position $3$, giving $B = [1,2,2]$.

## Solution (Python)

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos])
        a = [int(x) for x in data[pos + 1:pos + 1 + n]]
        pos += 1 + n
        top = max(a)
        in_b = set()
        b = []
        for v in a:
            # Forced only when this value is still missing from B.
            pick = v if v not in in_b else top
            in_b.add(pick)
            b.append(pick)
        out.append(" ".join(map(str, b)))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

- **Time:** $O(N)$ per test case
- **Space:** $O(N)$
