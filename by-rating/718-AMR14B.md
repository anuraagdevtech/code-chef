## Question

<span class="s1">Australia and New Zealand have started working on preparation for the World Cup 2015. There are N important venues (like hotels and stadiums) in the city. Out of these important venues, there is one central location where the opening and closing ceremony will be held. There is an existing network of bidirectional roads connecting these venues. The organizing committee has planned to decorate some of these roads that will be used for commuting. They have decided to choose the roads to decorate such that there is exactly one decorated path to all the venues from the central location.</span>

<span class="s1">New Zealand is supposed to decorate these roads and Australia has taken up the responsibility of providing transportation. Only decorated roads can be used for transportation. Australia wanted to save fuel costs, and so they wanted to choose the decorated roads to minimize the total sum of distances to all venues from the central location. However, New Zealand had their own plans to minimize decoration cost by choosing the decorated roads such that the sum of the length of the chosen roads will be minimized.</span>

<span class="s1">To prevent a fight breaking out between these two rivals before they even step on to the field, you have to help them by reporting if there is a solution in which the two rivals could choose the same set of roads while satisfying their respective constraints.</span>

<span class="s1">**Input:**</span>

<span class="s1">For each test first line contains N and M which are number of venues and total number of roads respectively.</span>

<span class="s1">Then next M lines for each case contains u, v and w - indicating that there is a bidirectional road of distance w between locations u and v.</span>

<span class="s1">The central location is identified with location 0.</span>

<span class="s1">**Output:**</span>

<span class="s1">For each test case, output the required answer on a separate line. If there is a valid plan, then print “YES”. Else, print “NO” (quotes for clarity).</span>

<span class="s1">Note: If any of the venues is not reachable from the central location, then print “NO”.</span>

<span class="s1">**Constraints:**</span>

<span class="s1">1 <= T <= 10000</span>

<span class="s1">1 <= N <= 20000</span>

<span class="s1">0 <= M <= 40000</span>

<span class="s1">0 <= u < N</span>

<span class="s1">0 <= v < N</span>

<span class="s1">u != v</span>

<span class="s1">1 <= w <= 10^9</span>

<span class="s1">The sum of values of N over all test cases will not be more than 1000000.</span>

<span class="s1">The sum of values of M over all test cases will not be more than 2000000.</span>

## Approach

With positive edge lengths, a tree minimises the sum of distances from root zero exactly when every root-to-vertex path is a shortest path in the original graph. For each non-root vertex, choose the cheapest possible last edge among all its shortest paths. Distances strictly increase along such edges, so these independent choices form a tree and minimise total edge weight among shortest-path trees.

Run Dijkstra, breaking equal-distance relaxations by the smaller last-edge weight. Separately compute an MST using Prim's algorithm. A common optimal tree exists exactly when the sum of chosen shortest-path-tree edges equals the MST weight. Reject disconnected graphs.

## Solution

```python
import sys
from heapq import heappush,heappop


def main() -> None:
    tokens = iter(sys.stdin.buffer.read().split())
    out = []
    for _ in range(int(next(tokens))):
        n,m = int(next(tokens)),int(next(tokens))
        graph = [[] for _ in range(n)]
        for _ in range(m):
            u,v,w = (int(next(tokens)) for _ in range(3))
            graph[u].append((v,w))
            graph[v].append((u,w))
        infinity = 10**30
        distance = [infinity]*n
        last = [infinity]*n
        distance[0] = last[0] = 0
        heap = [(0,0)]
        while heap:
            d,u = heappop(heap)
            if d != distance[u]:
                continue
            for v,w in graph[u]:
                candidate = d+w
                if candidate < distance[v]:
                    distance[v],last[v] = candidate,w
                    heappush(heap,(candidate,v))
                elif candidate == distance[v]:
                    last[v] = min(last[v],w)
        if any(d == infinity for d in distance):
            out.append('NO')
            continue
        seen = [False]*n
        heap = [(0,0)]
        mst = 0
        while heap:
            weight,u = heappop(heap)
            if seen[u]:
                continue
            seen[u] = True
            mst += weight
            for v,w in graph[u]:
                if not seen[v]:
                    heappush(heap,(w,v))
        out.append('YES' if sum(last) == mst else 'NO')
    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    main()
```

## Edge cases

- Vertices are zero-based.
- Equal shortest distances may have different last-edge costs.
- Disconnected graphs return `NO`.
- Positive weights ensure parent choices cannot create a cycle.

## Dry run

For edges `0-1:1,0-2:2,1-2:2`, cheapest shortest-path edges cost `1+2=3`, matching the MST. Both objectives can use the same tree, so the answer is `YES`.
