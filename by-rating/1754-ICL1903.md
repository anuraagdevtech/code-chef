## Question

Luke, an intergalactic traveller went on a trip across the universe and got candies from the different planets he visited. He comes back with $N$ candies and decides to distribute them among his $M$ friends. However, Luke only wants a fair distribution of the candies as he loves everyone equally. (A fair distribution is one in which each of his friends receive an equal number of candies and each friend receives at least one candy.) If a fair distribution is not possible, he might throw away some candies and try to distribute the remaining candies in a similar manner.

If he can throw away exactly $K$ candies at a time (he can throw away candies multiple times), what is the minimum number of times he will need to throw away candies before achieving a fair distribution?

###Input:

- First line will contain $T$, number of testcases. Then the testcases follow.
- Each testcase contains of a single line of input, three integers $N, M, K$.

###Output:
For each testcase, output a single integer denoting the minimum number of times he will need to throw away candies before achieving a fair distribution. If a fair distribution is not possible, print   -1.

###Constraints
- $1 \leq T \leq 10^5$
- $2 \leq N,M,K \leq 10^9$

## Approach

Throwing away $K$ candies $t$ times leaves $N - tK$, and a fair split among $M$ friends means $M \mid (N - tK)$. So the task is the smallest non-negative solution of the **linear congruence**

$$tK \equiv N \pmod M$$

With $g = \gcd(K, M)$ this is solvable exactly when $g \mid N$; otherwise print $-1$. When it is solvable, dividing through gives $t \cdot (K/g) \equiv (N/g) \pmod{M/g}$ where $K/g$ is now invertible, so

$$t \equiv \frac{N}{g} \cdot \left(\frac{K}{g}\right)^{-1} \pmod{M/g}$$

and the smallest non-negative residue is the answer. Note $t = 0$ comes out automatically when $N$ is already divisible by $M$.

One physical check remains: Luke cannot throw away more candies than he has, so the minimal $t$ must also satisfy $tK \leq N$. The solutions form an increasing arithmetic progression, so if the smallest one is already unaffordable, no larger one helps and the answer is $-1$.

The samples: $N = 28, M = 6, K = 2$ has $g = 2$ dividing $28$, and $2t \equiv 4 \pmod 6$ reduces to $t \equiv 2 \pmod 3$, so $t = 2$ — throwing $4$ away leaves $24$, four each. And $N = 78, M = 5, K = 3$ has $g = 1$, with $3t \equiv 3 \pmod 5$ giving $t = 1$: $75$ candies, fifteen each.

## Solution (Python)

```python
import sys
from math import gcd


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    out = []
    for i in range(t):
        n, m, k = (int(data[1 + 3 * i]), int(data[2 + 3 * i]), int(data[3 + 3 * i]))
        g = gcd(k, m)
        if n % g:
            out.append("-1")              # tK can never hit N modulo M
            continue
        mod = m // g
        throws = (n // g) * pow(k // g, -1, mod) % mod if mod > 1 else 0
        # He cannot throw away more candies than he has.
        out.append(str(throws) if throws * k <= n else "-1")
    sys.stdout.write("\n".join(out) + "\n")


main()
```
