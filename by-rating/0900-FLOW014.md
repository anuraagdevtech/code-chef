## Question

A certain type of steel is graded according to the following conditions.

1. **Hardness** of the steel must be greater than 50
2. **Carbon content** of the steel must be less than 0.7
3. **Tensile strength** must be greater than 5600

The grades awarded are as follows:
- Grade is 10 if all three conditions are met
- Grade is 9 if conditions (1) and (2) are met
- Grade is 8 if conditions (2) and (3) are met
- Grade is 7 if conditions (1) and (3) are met
- Grade is 6 if only one condition is met
- Grade is 5 if none of the three conditions are met

Write a program to display the grade of the steel, based on the values of hardness, carbon content and tensile strength of the steel, given by the user.

**Input**

The first line contains an integer **T**, total number of testcases. Then follow **T** lines, each line contains three numbers **hardness**, **carbon content** and **tensile strength** of the steel.

**Output**

For each test case, print Grade of the steel depending on Conditions, in a new line.

## Constraints

- 1 **≤** **T** **≤** 1000
- 0 **≤** **hardness, carbon content, tensile strength** **≤** 10000

## Sample

**Sample input**

```
3 
53 0.6 5602
45 0 4500
0 0 0
```

**Sample output**

```
10
6
6
```

## Approach

Three independent tests are applied to each sample:

1. hardness $> 50$
2. carbon content $< 0.7$
3. tensile strength $> 5600$

The grade then depends on *which* subset passed, not merely how many — grades $9$, $8$ and $7$ all correspond to two conditions met but distinguish which pair. So evaluate the three booleans once and branch on the combination.

The cleanest reading of the rules: grade $10$ for all three, then a specific grade for each pair, then $6$ for exactly one and $5$ for none. Note the pair-to-grade mapping is not in an obvious order — $(1,2) \to 9$, $(2,3) \to 8$, $(1,3) \to 7$ — so it has to be read off the statement rather than guessed from the count.

Two practical traps.

**Carbon content is not an integer.** It is compared against $0.7$, so the value must be parsed as a float. Reading it as an `int` would fail on the sample's $0.6$ outright.

**The comparisons are strict in all three cases**, and the middle one points the other way: carbon must be *less than* $0.7$ while the other two must *exceed* their thresholds. Sample case 3, with all values zero, passes condition 2 alone — $0 < 0.7$ — giving grade $6$ rather than $5$. That is the case that catches a solution which assumes all-zero means nothing passed.

## Solution (Python)

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    out = []
    for i in range(t):
        hardness = float(data[1 + 3 * i])
        carbon = float(data[2 + 3 * i])      # not an integer: compared to 0.7
        tensile = float(data[3 + 3 * i])
        c1 = hardness > 50
        c2 = carbon < 0.7
        c3 = tensile > 5600
        if c1 and c2 and c3:
            g = 10
        elif c1 and c2:
            g = 9
        elif c2 and c3:
            g = 8
        elif c1 and c3:
            g = 7
        elif c1 or c2 or c3:
            g = 6
        else:
            g = 5
        out.append(str(g))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

- **Time:** $O(1)$ per test case
