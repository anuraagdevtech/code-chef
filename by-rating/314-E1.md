# 314. The White Knight

> [`E1`](https://www.codechef.com/problems/E1) &middot; difficulty **1530** &middot; time limit **1s** &middot; Jump from 2* to 3* (Level 3)

## Topic used

| | |
|---|---|
| **Topic** | Dynamic Programming |
| **Technique** | Layered DP over columns of a DAG |
| **Complexity class** | Quadratic $O(n^2)$ |

| **Space** | $O(N)$ |

## Question

You are given a chessboard of size NxN. There is a white knight and several black pawns located on the board. The knight can move similarly to the normal knight in the game of chess; however it can only move towards the right of the board (see the below figure).

<img src="https://s3.amazonaws.com/codechef_shared/download/Images/whitekn.png" alt="" />

The mission of the knight is to capture as many black pawns as possible. Its journey ends when it moves to the rightmost column of the board.

Compute the maximum number of black pawns the white knight can capture.

**Input**

The first line contains t, the number of test cases (about 10). Then t test cases follow.

Each test case has the following form:

- The first line contains N, the size of the chessboard (4 ≤ N ≤ 1000).

- Then N lines follow, each line containing N characters which may be '.', 'K' or 'P', corresponding to the empty cell, the white knight, and the black pawn, respectively. There is exactly one 'K' character in the whole of the board.

**Output**

For each test case, print in a single line the maximum number of black pawns that can be captured.

## Constraints

- $t \approx 10$ (the statement says "about 10")
- $4 \leq N \leq 1000$
- each cell is '.', 'K' or 'P', and there is exactly one 'K' on the board

## Sample

**Sample input**

```
1
5
K....
..P..
.P...
...P.
.....
```

**Sample output**

```
2
```

## Approach

Because the knight may only move rightwards, its four moves — $(r \pm 1, c+2)$ and $(r \pm 2, c+1)$ — always **increase the column**. That makes the move graph a DAG layered by column, so a left-to-right sweep is a valid topological order and no search or cycle handling is needed.

Let $\mathrm{dp}[r][c]$ be the most pawns capturable on a journey that ends standing on $(r,c)$. Relax forward from each reachable cell:

$$\mathrm{dp}[r'][c'] \leftarrow \max\bigl(\mathrm{dp}[r'][c'],\; \mathrm{dp}[r][c] + [\,(r',c') \text{ holds a pawn}\,]\bigr)$$

Only **landing** cells score — a knight jumps over whatever lies between — so the pawn bonus attaches to the destination.

Pushing forward rather than pulling backward lets the table be a **rolling window of three columns**: a cell in column $c$ reaches only $c+1$ and $c+2$, so columns before $c$ are never needed again. That keeps memory at $O(N)$ instead of the $10^6$ cells a full table would need at $N = 1000$.

The journey ends on reaching the rightmost column, so the answer is the best value over column $N$ — *not* the best anywhere, which would let the knight stop early on a richer cell. Since $N \geq 4$, every column has a legal onward move (at least one of $r \pm 2$ stays on the board), so the last column is always reachable.

In the sample the knight starts at $(1,1)$ and takes $(2,3)$ then $(4,4)$, collecting two pawns, before stepping to $(2,5)$ to finish. Reaching the pawn at $(3,2)$ instead scores only $1$, since from there no further pawn is reachable — the greedy "take the nearest pawn" choice is exactly what the DP has to overrule.

## Solution

```python
import sys

NEG = -1
PAWN = 0x50


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos])
        board = data[pos + 1:pos + 1 + n]
        pos += 1 + n
        start = next(r for r in range(n) if board[r].find(b"K") >= 0)
        # Rolling window: a column only ever feeds the next two.
        cur = [NEG] * n
        nxt1 = [NEG] * n
        nxt2 = [NEG] * n
        cur[start] = 0
        best = NEG
        for c in range(n):
            if c == n - 1:
                best = max(cur)
                break
            for r in range(n):
                here = cur[r]
                if here < 0:
                    continue
                for dr in (-2, 2):                 # column + 1
                    rr = r + dr
                    if 0 <= rr < n:
                        gain = here + (board[rr][c + 1] == PAWN)
                        if gain > nxt1[rr]:
                            nxt1[rr] = gain
                if c + 2 < n:
                    for dr in (-1, 1):             # column + 2
                        rr = r + dr
                        if 0 <= rr < n:
                            gain = here + (board[rr][c + 2] == PAWN)
                            if gain > nxt2[rr]:
                                nxt2[rr] = gain
            cur, nxt1, nxt2 = nxt1, nxt2, [NEG] * n
        out.append(str(max(best, 0)))
    sys.stdout.write("\n".join(out) + "\n")


main()
```
