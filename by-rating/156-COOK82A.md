## Question

Today is the final round of La Liga, the most popular professional football league in the world. Real Madrid is playing against Malaga and Barcelona is playing against Eibar. These two matches will decide who wins the league title. Real Madrid is already 3 points ahead of Barcelona in the league standings. In fact, Real Madrid will win the league title, except for one scenario: If Real Madrid loses against Malaga, and Barcelona wins against Eibar, then the La Liga title will go to Barcelona. In any other combination of results, Real Madrid will win the title.

You will be given multiple scenarios for these two games, where in each one you will be given the number of goals each team scored in their respective match. A team wins a match if it scores more than the opponent. In case they score the same number of goals, it's a draw. Otherwise, the team loses the game. You are asked to tell the winner of the La Liga title in each scenario.

**Input**

The first line contains a single number **T**, the number of scenarios.
Each scenario is described by four lines. Each line starts with a team name followed by the number of goals this team scored in its corresponding match. (Barcelona plays Eibar and Real Madrid plays Malaga). The names are given in any arbitrary order within a scenario.

**Output**

For each scenario, output a single line showing the title winner in case this scenario happens. It should be either "RealMadrid" or "Barcelona".

**Constraints**

- 1 ≤ **T** ≤ **500**

- 0 ≤ number of goals scored by a team in a match ≤ **20**

## Constraints

- 1 ≤ T ≤ 500
- 0 ≤ number of goals scored by a team in a match ≤ 20

## Sample

**Sample input**

```
2
Barcelona 2
Malaga 1
RealMadrid 1
Eibar 0
Malaga 3
RealMadrid 2
Barcelona 8
Eibar 6
```

**Sample output**

```
RealMadrid
Barcelona
```

## Approach

Real Madrid leads by $3$ points and takes the title in every scenario **except one**: Real Madrid loses *and* Barcelona wins. So the condition for Barcelona is a single conjunction:

$$\text{RealMadrid} < \text{Malaga} \quad\text{and}\quad \text{Barcelona} > \text{Eibar}$$

Everything else — Real Madrid drawing, Barcelona drawing, both winning, both losing — leaves Real Madrid champion. Enumerating the nine win/draw/loss combinations is unnecessary once the exception is written down directly.

The parsing is the part that needs care. Each scenario gives **four lines of `name goals`, in arbitrary order**, so the values cannot be read positionally. Building a dictionary from team name to goals and then looking up the four teams by name is the robust approach; assuming a fixed order would pass sample case 1 and fail case 2, where the lines begin with Malaga rather than Barcelona.

Note which pairs actually play each other: Barcelona faces Eibar, and Real Madrid faces Malaga. Comparing Barcelona's goals against Real Madrid's would be meaningless, since they are in different matches.

Sample case 1 shows a draw not counting as a loss: Real Madrid and Malaga both score $1$, so despite Barcelona beating Eibar the title stays with Real Madrid. Sample case 2 is the sole losing scenario.

Team names must be matched exactly — `RealMadrid` is written as one word with no space.

## Solution

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        # Four "name goals" pairs in arbitrary order, so index them by name.
        goals = {}
        for _ in range(4):
            goals[data[pos].decode()] = int(data[pos + 1])
            pos += 2
        # Barcelona takes the title only if Real Madrid lose and they win.
        barca = goals["RealMadrid"] < goals["Malaga"] and goals["Barcelona"] > goals["Eibar"]
        out.append("Barcelona" if barca else "RealMadrid")
    sys.stdout.write("\n".join(out) + "\n")


main()
```
