# 254. Sleepy Chef

> [`FILL01`](https://www.codechef.com/problems/FILL01) &middot; difficulty **1445** &middot; time limit **2s** &middot; Jump from 2* to 3* (Level 3)

> _Edge cases and dry run for this problem are still to be written._

## Topic used

| | |
|---|---|
| **Topic** | Greedy |
| **Technique** | Independent runs, each packed by division |
| **Complexity class** | Linear $O(n)$ |
| **Time** | $O(N)$ per test case |
| **Space** | $O(1)$ |

## Question

Chef has to work on a project for the next $N$ hours. He is given a work plan to do this, which is given to you as a binary string $S$ of length $N$. $S_i = 1$ if Chef has to work on the project during the $i$-th hour, and $S_i = 0$ if Chef is free during the $i$-th hour.

Chef would like to use some of his free time to take naps. He needs a minimum of $K$ consecutive hours of free time to take a nap. What is the maximum number of naps that Chef can take during the next $N$ hours?

Note that it is allowed for one nap to immediately follow another, i.e, Chef can wake up from one nap and then immediately take another one (if he has enough free time to do so), and these will be counted as different naps.

**Input**

- The first line of input contains a single integer $T$, denoting the number of test cases. The description of $T$ test cases follows.
- The first line of each test case contains two space-separated integers $N$ and $K$ respectively.
- The second line of each test case contains a binary string $S$ of length $N$ denoting Chef's work plan.

**Output**

- For each test case, print a single line containing one integer — the maximum number of naps that Chef can take.

## Constraints

- $1 \leq T \leq 10^5$
- $1 \leq N \leq 10^5$
- $1 \leq K \leq N$
- Sum of $N$ over all test cases doesn't exceed $2 \cdot 10^5$
- $S$ is a binary string, i.e, each character of $S$ is either `0` or `1`.

## Sample

**Sample input**

```
3
4 1
1010
4 2
0100
11 3
00100000001
```

**Sample output**

```
2
1
2
```

<details><summary>Explanation</summary>

**Test Case 1:** Chef can take two naps starting from the $2^{nd}$ and $4^{th}$ hours respectively.

**Test Case 2:** Chef can take a nap starting from the $3^{rd}$ hour.

**Test Case 3:** Chef can take one nap starting from the $5^{th}$ hour and another starting from the $8^{th}$ hour.

</details>

## Approach

A nap needs $K$ **consecutive** free hours, so it must lie inside a single maximal run of zeros — no nap can span a working hour. The runs are therefore independent, and the answer is the sum of what each run can hold.

Within a run of length $\ell$, naps are disjoint blocks of exactly $K$ hours, and consecutive naps are explicitly allowed to touch. So a run holds at most $\lfloor \ell / K \rfloor$ naps, and packing them back to back from the left attains that bound. Hence

$$\text{answer} = \sum_{\text{runs}} \left\lfloor \frac{\ell}{K} \right\rfloor$$

The leftover $\ell \bmod K$ hours are simply wasted — they cannot be combined with another run's remainder, which is the trap in treating the problem as "total free hours divided by $K$". Sample 3 shows the difference plainly: `00100000001` with $K = 3$ has $10$ free hours, so the naive division would say $3$, but the runs are $2$ and $8$, giving $0 + 2 = 2$.

Sample 2 is the same trap in miniature: `0100` with $K = 2$ has three free hours but runs of $1$ and $2$, so only one nap. And sample 1 with $K = 1$ shows the other extreme — every free hour is its own nap, so the answer is the count of zeros, $2$.

A single pass with a running counter suffices: on a `0` extend the run, on a `1` flush it. Remember to flush the final run after the loop, which is the usual off-by-one here.

## Solution

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    out = []
    for i in range(t):
        k = int(data[2 + 3 * i])
        plan = data[3 + 3 * i]
        naps = 0
        # Leftovers cannot be pooled across runs, so divide each run alone.
        for run in plan.split(b"1"):
            naps += len(run) // k
        out.append(str(naps))
    sys.stdout.write("\n".join(out) + "\n")


main()
```
