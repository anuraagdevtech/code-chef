space: $O(N^2)$
complexity_note: Auxiliary space excludes the buffered input and output.

A team can still be champion exactly when the unfinished matches can be decided so that nobody ends with more wins than it. The candidate should obviously win all of its own unfinished matches, which fixes its final tally $L$.

For the other unfinished matches, start from an arbitrary orientation: give each one to the lower-numbered team and add a unit edge from that team to its opponent, meaning "this win can be handed over". A team that now sits above $L$ must give away its excess, so it is fed from the source with that excess; a team below $L$ can absorb the difference and is connected to the sink. The candidate can be champion if and only if the whole excess can be routed, which is a maximum-flow question answered with Dinic's algorithm. If some team already has more than $L$ finished wins, the answer is immediately no.

Run the test once per team and print one character each.

## Edge cases

- A team whose finished wins already exceed the candidate's best possible tally rules the candidate out before any flow is built.
- Co-champions are allowed, so rivals may finish level with the candidate - the limit is $\le L$, not $< L$.
- With no unfinished matches the answer is simply whether the team has the maximum number of wins.
- Matches involving the candidate are not part of the network; they are all counted as wins for it.

## Dry run

Second sample, four teams. Finished wins are `[2, 0, 0, 3]` and the only unfinished match is team 2 against team 3.

- Team 1: best tally 2, but team 4 already has 3 wins, so `0`.
- Teams 2 and 3: best tally 1 each, again below team 4, so `0`.
- Team 4: limit 3. Orient the open match towards team 2, giving `[2, 1, 0]` for the rivals; no one exceeds 3, the required flow is 0, so `1`.

Output `0001`.
