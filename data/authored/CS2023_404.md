topic: Dynamic Programming
subtopic: Subsequence-counting DP summed over all replacements
time: $O(N)$ per test case
space: $O(1)$
complexity_note: Auxiliary space excludes the buffered input and output.
---
Count, over all strings generated so far, the total number of subsequences equal to `4`, `40` and `404`, together with the number of generated strings.

- A literal `4` can start a new subsequence in every string (`count_4 += strings`) and can finish any `40` (`count_404 += count_40`).
- A literal `0` extends every `4` to `40` (`count_40 += count_4`).
- A `*` splits every string into two. Every existing subsequence survives in both copies, so all counts double; in addition the copy where it becomes `4` gets the contributions of a literal `4`, and the copy where it becomes `0` those of a literal `0`:

$$\text{strings}' = 2\,\text{strings},\quad c_4' = 2 c_4 + \text{strings},\quad c_{40}' = 2 c_{40} + c_4,\quad c_{404}' = 2 c_{404} + c_{40}.$$

All four updates use the old values. The answer is the final `count_404`.

## Edge cases

- No `*` at all: the plain count of `404` subsequences.
- The updates for `*` must be simultaneous, hence the tuple assignment.
- For a literal `4`, `count_404` uses `count_40` which that character does not change, so the order of the two updates is irrelevant.
- Everything is modulo $10^9 + 7$.

## Dry run

`S = 4*4*`, state (strings, `4`, `40`, `404`):

- start: (1, 0, 0, 0)
- `4`: (1, 1, 0, 0)
- `*`: (2, 3, 1, 0)
- `4`: (2, 5, 1, 1)
- `*`: (4, 12, 7, 3)

Answer 3.
