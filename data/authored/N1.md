topic: Dynamic Programming
subtopic: BFS distances between treasures and subset tour DP
time: $O((K+2)N^2+2^K K^2)$ per test case for $K$ treasures
space: $O(N^2+2^K K)$
complexity_note: Auxiliary space excludes the buffered input and output.
---
Only the order of visiting treasures matters. BFS from the start, each treasure, and the finish yields shortest distances between these special cells. If any treasure or the finish is unreachable from the start, no valid route exists.

For nonempty treasure subset $mask$, let $dp[mask][j]$ be the least travel time starting at the entrance, visiting the treasures in $mask$, and ending at treasure $j$. Extend to each unvisited treasure using the precomputed distances. Once all treasures are included, add the distance to the exit and take the minimum. A shortest segment may pass through additional treasures, which never invalidates a route; the metric tour optimum still equals the shortest walk collecting everything.

## Edge cases

- With no treasures, return the ordinary start-to-finish shortest distance.
- The start and finish are guaranteed empty.
- Paths may revisit cells.
- A treasure unreachable from the start makes the answer minus one.

## Dry run

In sample two, the only treasure is at the top-right of a three-by-three open grid. Start to treasure takes two steps, then treasure to finish takes two, for total four.
