---
topic: Dynamic Programming
subtopic: Distinct subsequences by end position, with last-occurrence correction
time: $O(N \cdot \min(N, L))$ per test case
space: $O(\min(N, L))$
complexity_note: Auxiliary space excludes the buffered input and output.
---
Count distinct subsequences of the master sequence, grouped by where the robot ends, never letting it leave $[0, L]$.

Process the master sequence left to right. Appending the current sign to every subsequence counted so far creates new sequences whose end positions are shifted by one; positions that would fall outside the runway are simply dropped, which also removes every sequence that would leave the runway at this step. Some of these "new" sequences were already created when the same sign last appeared - exactly the ones produced then - so subtract the array of sequences created at the previous occurrence of this sign. This is the classic distinct-subsequence recurrence, applied position-wise.

Only positions within $N$ of the start are reachable, so the array is limited to $[\max(0, A - N), \min(L, A + N)]$.

## Edge cases

- The empty sequence is valid and is counted when the start equals the target.
- A target outside the reachable band gives 0.
- The modulus is the unusual 7051954 given in the statement, and subtraction needs the result brought back to non-negative.
- Sequences are compared as strings, not by which master positions they use - hence the duplicate correction.

## Dry run

`N = 6, L = 1, A = 0, B = 0`, master `+-+-+-`. Positions are 0 and 1; write the counts as `[at 0, at 1]`.

- start `[1, 0]`
- `+`: creates `[0, 1]` -> `[1, 1]`
- `-`: creates `[1, 0]` -> `[2, 1]`
- `+`: creates `[0, 2]`, minus the previous `+` batch `[0, 1]` -> `[2, 2]`
- `-`: creates `[2, 0]`, minus `[1, 0]` -> `[3, 2]`
- `+`: creates `[0, 3]`, minus `[0, 2]` -> `[3, 3]`
- `-`: creates `[3, 0]`, minus `[2, 0]` -> `[4, 3]`

Answer 4: the empty sequence, `+-`, `+-+-` and `+-+-+-`.
