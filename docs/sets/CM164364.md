# 201. Chocolate Monger

> CodeChef problem code [`CM164364`](https://www.codechef.com/problems/CM164364) &middot; difficulty **1369** &middot; time limit **1s**

| | |
|---|---|
| **Topic** | Sets |
| **Technique** | Distinct count capped by a budget |
| **Time** | $O(n)$ per test case |
| **Space** | $O(n)$ |
| **Roadmap course** | Level up from 1* to 2* (Level 2) |

## Question

There are $n$ chocolates, and you are given an array of $n$ numbers where the $i$-th number $A_i$ is the flavour type of the $i$-th chocolate. Sebrina wants to eat as many different types of chocolates as possible, but she also has to save at least $x$ number of chocolates for her little brother.

Find the maximum possible number of distinct flavour types Sebrina can have.

**Input**

The first line contains an integer $T$ --- the number of test cases.
- The first line of each test case consists of two integers $n$, $x$ - The number of chocolates Sabrina has and the number of chocolates she has to save for her brother, respectively.
- The second line contains $n$ integers $A_1,\ldots, A_n$, where the $i$-th chocolate has type $A_i$.

**Output**

For each test case, output a single integer denoting the maximum possible number of distinct chocolate flavours Sabrina can eat.

## Constraints

- $1\le T\le 10$
- $1 \le x \le  n \le 2 \cdot 10^5  $
- $1 \le A_{i} \le 10^9$
- Sum of $n$ over all test cases do not exceed $ 2 \cdot 10^5  $

## Sample

**Sample input**

```
3
2 1
1 2
4 2
1 1 1 1
5 3
50 50 50 100 100
```

**Sample output**

```
1
1
2
```

<details><summary>Explanation</summary>

**Test case $1$:** In the first case, the maximum number of chocolates Sebrina can have is $1$ as she has to leave $1$ chocolate for her brother. Thus, the maximum number of distinct chocolates is also $1$.

**Test case $2$:** Sebrina has to leave $2$ chocolates for her brother. She can eat any $2$ chocolates. Since all the chocolates have the same flavor, it does not matter which chocolates she eats. The maximum number of distinct chocolates would be $1$.

**Test case $3$:** Sebrina needs to save $3$ chocolates for her brother. She can eat any $2$ chocolates. To maximize the number of distinct chocolates, she can eat chocolates $1$ and $5$ with flavors $50$ and $100$ respectively. Thus maximum number of distinct chocolates is $2$.

</details>

## Approach

Sebrina must leave $x$ chocolates for her brother, so she may eat at most $n - x$ of them. Two independent ceilings apply to how many **distinct** flavours she can manage:

- She cannot taste more flavours than exist, so at most $d = |\{A_1, \ldots, A_n\}|$.
- She cannot taste more flavours than chocolates she eats, so at most $n - x$.

The answer is

$$\min(d,\; n - x)$$

Both bounds are achievable simultaneously: to collect $k$ distinct flavours she eats exactly one chocolate of each, so $k$ chocolates suffice. There is never a reason to eat two of the same flavour while a new one is available, which is why no greedy search is needed.

Each limit binds in a different sample. Case 1 has two flavours but allows only one chocolate, so the budget binds. Case 2 allows two chocolates but has only one flavour, so the variety binds. Case 3 has both equal at $2$.

Counting distinct values is a single pass into a Python `set`; the flavour values reach $10^9$, so a frequency array indexed by flavour is not an option, but hashing is unaffected.

The constraint $x \leq n$ guarantees $n - x \geq 0$, so the answer is never negative — though it may legitimately be $0$ when $x = n$ and she eats nothing.

## Solution (Python)

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n, x = int(data[pos]), int(data[pos + 1])
        flavours = set(data[pos + 2:pos + 2 + n])
        pos += 2 + n
        # Limited both by how many flavours exist and by how many she may eat.
        out.append(str(min(len(flavours), n - x)))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## Complexity

- **Time:** $O(n)$ per test case
- **Space:** $O(n)$

## Edge cases

- **Two separate ceilings.** She cannot exceed the number of flavours that exist, nor the $n - x$ chocolates she is allowed to eat — and the sample has one row binding on each: row 1 is capped by the budget, row 2 by the single flavour available.
- **Row 3 is the case where both agree** ($2$ flavours and $2$ chocolates to spare), so the sample never exposes a wrong ordering of the two bounds.
- **$x = n$**: she may eat nothing at all and the answer is $0$.
- **She must save *at least* $x$**, so eating fewer than $n - x$ is allowed — which is why the answer is a minimum rather than an exact count.
- **Duplicates are free to discard.** Row 2 has four identical chocolates and a budget of $2$; eating one is as good as eating two.
- **$A_i$ up to $10^9$** — the values are only grouped, so the raw byte tokens serve as set keys with no integer conversion.

## Dry run

| $n$ | $x$ | flavours | distinct | budget $n - x$ | output |
|---:|---:|---|---:|---:|---:|
| 2 | 1 | $1, 2$ | 2 | 1 | `1` |
| 4 | 2 | $1,1,1,1$ | 1 | 2 | `1` |
| 5 | 3 | $50,50,50,100,100$ | 2 | 2 | `2` |
