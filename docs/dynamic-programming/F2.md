# 601. Bytelandian Robots

> CodeChef problem code [`F2`](https://www.codechef.com/problems/F2) &middot; difficulty **1844** &middot; time limit **0.5s**

| | |
|---|---|
| **Topic** | Dynamic Programming |
| **Technique** | Distinct subsequences by end position, with last-occurrence correction |
| **Time** | $O(N \cdot \min(N, L))$ per test case |
| **Space** | $O(\min(N, L))$ |
| **Roadmap course** | Rise from 3* to 4* (Level 4) |

## Question

The Bytelandian Robotic Deparment has just succesfully made a robot that can be programmed to   move. Our robot can perform two type of movements: moving one step to the left or one step to the   right.

Our robot moves according to the instruction from its control sequence. A control sequence of the   robot is a string consisting of only two type of characters: '+' and '-' symbols, in which '+' means   a rightward step and '-' means a leftward step. For example, '+--' is a control sequence that instruct the robot to go one step to the right   followed by two steps to the left.

Our robot also has a master control sequence (MCQ), which is a string of N characters '+' and   '-'. **Any valid control sequence of the robot must be a subsequence of the MCQ**. Recall that a   subsequence is a sequence obtained by removing some characters of the initial sequence. An empty   sequence is also a subsequence of the MCQ.

Our robot is currently placed on a runway of length L, in which the leftmost point has coordinate 0   and the rightmost point has coordinate L. Intially our robot stands at the point at coordinate A. It   needs to move to the point at coordinate B. Of course, it cannot go outside the runway.

How many different control sequences are there that make the robot go from A to B?

**Input**

The first line contains t, the number of test cases (about 50). Then t test cases follow. Each   test case has the following form:

- The first line contains four integers N, L, A, B (1 ≤ N ≤ 500, 1 ≤ L ≤   10^9, 0 ≤ A, B ≤ L).

-  The second line contains the MCQ which is a string of exactly N characters. The MCQ contains only   symbols '+' and '-'.

**Output**

For each test case, print a single number that is the number of different control sequences that   could make the robot to go from A to B. Since the result may be a very large number, you only need   to print the remainder of the result when dividing by 7051954.

## Constraints

- About 50 test cases.
- 1 <= N <= 500.
- 1 <= L <= 10^9.
- 0 <= A, B <= L.
- The MCQ contains only the symbols + and -.

## Sample

**Sample input**

```
5
6 6 0 0
+-+-+-
6 6 3 3
+-+-+-
6 1 0 0 
+-+-+-
6 6 1 4
+-+-+-
6 6 2 6
+-+-+-
```

**Sample output**

```
5 
9
4
1
0
```

<details><summary>Explanation</summary>

Case 1: the different control sequences are +-, +-+-, ++--, +-+-+- and the empty sequence.

Case 2: same as case 1 together with 4 additional sequences: -+, -+-+, -++-, +--+. These additional   sequences no longer make the robot go outside the runway as in case 1.

Case 3: same as case 1 but without the sequence ++-- since it will make the robot go outside the   runway

Case 4: there is only one possible control sequence: +++

Case 5: there is no way for the robot to go to coordinate 6

</details>

## Approach

Count distinct subsequences of the master sequence, grouped by where the robot ends, never letting it leave $[0, L]$.

Process the master sequence left to right. Appending the current sign to every subsequence counted so far creates new sequences whose end positions are shifted by one; positions that would fall outside the runway are simply dropped, which also removes every sequence that would leave the runway at this step. Some of these "new" sequences were already created when the same sign last appeared - exactly the ones produced then - so subtract the array of sequences created at the previous occurrence of this sign. This is the classic distinct-subsequence recurrence, applied position-wise.

Only positions within $N$ of the start are reachable, so the array is limited to $[\max(0, A - N), \min(L, A + N)]$.

## Solution (Python)

```python
import sys


def main() -> None:
    tokens = iter(sys.stdin.buffer.read().split())
    out = []
    MOD = 7051954
    for _ in range(int(next(tokens))):
        n, length, start, target = (int(next(tokens)) for _ in range(4))
        master = next(tokens)
        low = max(0, start - n)
        high = min(length, start + n)
        ways = [0] * (high - low + 1)
        ways[start - low] = 1
        last = {}
        for ch in master:
            step = 1 if ch == 43 else -1
            created = [0] * len(ways)
            if step == 1:
                for j in range(1, len(ways)):
                    created[j] = ways[j - 1]
            else:
                for j in range(len(ways) - 1):
                    created[j] = ways[j + 1]
            old = last.get(ch)
            for j in range(len(ways)):
                ways[j] = (ways[j] + created[j] - (old[j] if old else 0)) % MOD
            last[ch] = created
        out.append(str(ways[target - low] if low <= target <= high else 0))
    print('\n'.join(out))


if __name__ == "__main__":
    main()
```

## Complexity

- **Time:** $O(N \cdot \min(N, L))$ per test case
- **Space:** $O(\min(N, L))$
- Auxiliary space excludes the buffered input and output.

## Edge cases

- The empty sequence is valid and is counted when the start equals the target.
- A target outside the reachable band gives 0.
- The modulus is the unusual 7051954 given in the statement, and subtraction needs the result brought back to non-negative.
- Sequences are compared as strings, not by which master positions they use - hence the duplicate correction.

## Dry run

`N = 6, L = 1, A = 0, B = 0`, master `+-+-+-`. Positions are 0 and 1; write the counts as `[at 0, at 1]`.

- start `[1, 0]`
- `+`: creates `[0, 1]` -> `[1, 1]`
- `-`: creates `[1, 0]` -> `[2, 1]`
- `+`: creates `[0, 2]`, minus the previous `+` batch `[0, 1]` -> `[2, 2]`
- `-`: creates `[2, 0]`, minus `[1, 0]` -> `[3, 2]`
- `+`: creates `[0, 3]`, minus `[0, 2]` -> `[3, 3]`
- `-`: creates `[3, 0]`, minus `[2, 0]` -> `[4, 3]`

Answer 4: the empty sequence, `+-`, `+-+-` and `+-+-+-`.
