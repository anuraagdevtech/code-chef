# TDISTS

A tree’s bipartition sizes a,b give x=a^2+b^2 and y=2ab. Hence n=sqrt(x+y) and |a-b|=sqrt(x-y), which must be integral with matching parity and positive parts. A double star realizes any such bipartition.

Complexity: O(sqrt(x+y)) output time and space.

Validation: repository sample checks and deterministic differential checks where applicable; no online acceptance is claimed.
