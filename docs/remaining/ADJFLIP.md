# ADJFLIP

The number of ones on even indices minus that on odd indices is invariant. Alternating-complementing the string converts each allowed equal-pair flip into an adjacent swap of unequal symbols, so this invariant completely characterizes reachability. Compare it to both constant strings.

Complexity: O(N) time and O(1) extra space.

Validation: repository sample checks and deterministic differential checks where applicable; no online acceptance is claimed.
