# TWOAVG

For a fixed number z of appends, only K in A and 1 in B can help. Cross-multiply the mean inequality; as a function of the number x appended to A, the difference is a concave quadratic. Test its nearest integer vertex and endpoints. Feasibility is monotone in z, enabling binary search.

Complexity: O(N+M+log(answer+1)) time and O(1) extra space.

Validation: repository sample checks and deterministic differential checks where applicable; no online acceptance is claimed.
