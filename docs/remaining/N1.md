# Treasure Hunting (N1)

[Problem statement](https://www.codechef.com/problems/N1) · [Python solution](../../solutions/N1.py)

## Approach

BFS between the start, treasures and destination turns the maze into a metric graph. Held-Karp subset DP finds the shortest route visiting every treasure before reaching the destination. Any unreachable required point makes the answer -1.

## Complexity

- Time: O(N squared times treasures+2^treasures times treasures squared).
- Space: O(N squared+2^treasures times treasures).
