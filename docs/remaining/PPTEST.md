# Polo the Penguin and the Test (PPTEST)

[Problem statement](https://www.codechef.com/problems/PPTEST) · [Python solution](../../solutions/PPTEST.py)

## Approach

A question has value C_i*P_i and study cost T_i. Use descending-capacity 0/1 knapsack so each question is selected at most once.

## Complexity

- Time: O(NW).
- Space: O(W).
