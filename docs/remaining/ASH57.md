# ASH57

Any color present in B permits arbitrary permutations of all its A and B elements through cross-array swaps. Other A positions are fixed. Greedily select the smallest available value at least the previous chosen value; smaller choices cannot harm any later position.

Complexity: O(N log N) time and O(N) space.

Validation: repository sample checks and deterministic differential checks where applicable; no online acceptance is claimed.
