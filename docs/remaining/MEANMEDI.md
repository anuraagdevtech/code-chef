# MEANMEDI

Sort and fix the selected median. Cardinality-indexed bitset knapsacks provide all sums for the required number of elements strictly before and after it. For each reachable left sum find the nearest right sum by bit operations.

Complexity: O(NK S / word size + NS² / word size) bit-operation bound and O(NS) bits, S<=72000.

Reference: [CodeChef editorial](https://discuss.codechef.com/t/1000). Implementation and validation are original Python code.
