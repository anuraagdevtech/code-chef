# Maximal Score Path (RG_01)

[Problem statement](https://www.codechef.com/problems/RG_01) · [Python solution](../../solutions/RG_01.py)

## Approach

Build a maximum spanning tree with Kruskal. Its unique path between any pair maximizes the minimum edge weight among all original paths. Traverse that tree from every vertex to output the bottleneck matrix.

## Complexity

- Time: O(M log M+N squared).
- Space: O(N+M).
