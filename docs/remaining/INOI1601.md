# Wealth Disparity (INOI1601)

[Problem statement](https://www.codechef.com/problems/INOI1601) · [Python solution](../../solutions/INOI1601.py)

## Approach

Traverse from the supplied root while carrying the largest wealth among strict ancestors. Compare that maximum with each child's wealth before adding the child to the path. This version maximizes ancestor wealth minus descendant wealth, so a negative optimum remains valid.

## Complexity

- Time: O(N).
- Space: O(N).
