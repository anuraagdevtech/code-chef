# Soccer League (M3)

[Problem statement](https://www.codechef.com/problems/M3) · [Python solution](../../solutions/M3.py)

## Approach

Give the candidate all its unfinished wins. Orient the other unfinished games arbitrarily, then redistribute wins along residual edges between their teams. A source supplies each overfull team's excess and underfull teams drain to a sink. A feasible full flow is equivalent to a schedule where no rival exceeds the candidate's win limit.

## Complexity

- Time: O(N^5) conservative worst-case bound: N Dinic runs, each with O(N) vertices and O(N squared) edges; practical flows are smaller.
- Space: O(N squared).
