# IS IT DSU HARD!! (CFMAR04)

[Problem statement](https://www.codechef.com/problems/CFMAR04) · [Python solution](../../solutions/CFMAR04.py)

## Approach

Anagram equivalence is equality of the 26-letter frequency vector. Count each vector and report the largest class. The input contains one word list without a test-count prefix.

## Complexity

- Time: O(total characters).
- Space: O(26N).
