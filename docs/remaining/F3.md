# Curry Stained Napkin (F3)

[Problem statement](https://www.codechef.com/problems/F3) · [Python solution](../../solutions/F3.py)

## Approach

Flood-fill the folded 8-by-8 pattern and record which boundaries each component touches. Across 2^(N-3) mirrored copies per dimension, a component touching both boundaries has one connected row group, neither has k groups, only the original far boundary has k/2, and only the near boundary has k/2+1. Multiply row and column group counts and sum modulo 21945.

## Complexity

- Time: O(log N).
- Space: O(1).
