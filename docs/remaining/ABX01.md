# Strange Function (ABX01)

[Problem statement](https://www.codechef.com/problems/ABX01) · [Python solution](../../solutions/ABX01.py)

## Approach

For positive integers the repeated digit sum equals the residue modulo nine, with zero residue represented by nine. Compute A^N modulo nine with modular exponentiation.

## Complexity

- Time: O(log exponent).
- Space: O(1).
