# Maze of Digits (K3)

[Problem statement](https://www.codechef.com/problems/K3) · [Python solution](../../solutions/K3.py)

## Approach

BFS states combine a grid cell and the digit sum collected so far. Entering any digit adds it on every visit, so revisits remain distinct states. Nonnegative digits allow discarding sums above the target; the first target state is shortest.

## Complexity

- Time: O(rows times columns times target).
- Space: O(rows times columns times target).
