# CHEF7UP

Relative coordinate parity is invariant after full turns. On either side, the nearest same-parity officer can always move toward Chef and protects all officers beyond it. Chef can chase and eliminate each nearer opposite-parity officer by pushing the group toward the finite boundary. Count consecutive opposite-parity officers outward on each side. Escape is possible exactly when this count is N.

Complexity: O(N log N) time and O(N) space.

Validation: repository sample checks and deterministic differential checks where applicable; no online acceptance is claimed.

Reference: [official editorial](https://discuss.codechef.com/t/95739).
