# 557. Maximal Score Path

> CodeChef problem code [`RG_01`](https://www.codechef.com/problems/RG_01) &middot; difficulty **1836** &middot; time limit **1s**

| | |
|---|---|
| **Topic** | Graphs |
| **Technique** | Maximum spanning tree preserves all bottleneck paths |
| **Time** | $O(E\log E+V^2)$ overall |
| **Space** | $O(E+V)$ excluding the output |
| **Roadmap course** | Rise from 3* to 4* (Level 4) |

## Question

**Problem Statement**
 Given a weighted and undirected graph G = (V, E), let us define the score of an edge as its weight, and the score of a path as the minimum of the scores of its edges. For each pair of vertices (u, v), let us define a best path as a path with the maximal score, that starts at u and ends at v. Your task is to find out the score of a best path over all pairs of distinct vertices (u, v) given the description of the graph G.

**Input**

 The first line contains V, the number of vertices, and E, the number of edges in the graph. The graph will be weighted, undirected, simple (no self loops and no parallel edges), and connected. Each of the next E lines contains three non-negative integers u, v, and w, denoting that there is an edge (u, v) in the graph with a score of w. u and v are guaranteed to be distinct, and no edge will repeat in the input.

**Output**

 Output a total of V lines each containing V integers. The vth integer on the uth line should be 0 if u = v, or the score of a best path that starts at vertex u and ends at vertex v.

**Constraints**

2 ≤ V ≤ 1000

V - 1 ≤ E ≤ V(V - 1)/2

0 ≤ u, v ≤ V - 1

0 ≤ w ≤ 10^8

** Warning**
 Large Input/Output. Use faster Input/Output techniques.

## Constraints

2 ≤ V ≤ 1000

0 ≤ u, v ≤ V - 1
0 ≤ w ≤ 10^8

## Sample

**Sample input**

```
3 3
0 1 1
1 2 2
0 2 3
```

**Sample output**

```
0 2 3
2 0 2
3 2 0
```

## Approach

Build a maximum spanning tree using descending-weight Kruskal. For any pair of vertices, the minimum-weight edge on their tree path equals the largest achievable path bottleneck in the original graph. If a better bottleneck existed, it would cross the cut of that minimum tree edge with a heavier edge, contradicting maximum spanning-tree optimality.

Traverse the tree once from each start vertex, carrying the minimum weight seen so far. Output those bottlenecks as a row, with zero on the diagonal. This takes quadratic traversal time, matching the number of output entries.

## Solution (Python)

```python
import sys


def main() -> None:
    tokens = iter(map(int,sys.stdin.buffer.read().split()))
    n,m = next(tokens),next(tokens)
    edges = []
    for _ in range(m):
        u,v,w = next(tokens),next(tokens),next(tokens)
        edges.append((w,u,v))
    edges.sort(reverse=True)
    parent = list(range(n))
    size = [1]*n
    def find(u):
        while parent[u] != u:
            parent[u] = parent[parent[u]]
            u = parent[u]
        return u
    tree = [[] for _ in range(n)]
    for w,u,v in edges:
        a,b = find(u),find(v)
        if a != b:
            if size[a] < size[b]:
                a,b = b,a
            parent[b] = a
            size[a] += size[b]
            tree[u].append((v,w))
            tree[v].append((u,w))
    for start in range(n):
        answer = [0]*n
        stack = [(start,-1,10**30)]
        while stack:
            u,p,bottleneck = stack.pop()
            for v,w in tree[u]:
                if v != p:
                    answer[v] = min(bottleneck,w)
                    stack.append((v,u,answer[v]))
        print(' '.join(map(str,answer)))

if __name__ == '__main__':
    main()
```

## Complexity

- **Time:** $O(E\log E+V^2)$ overall
- **Space:** $O(E+V)$ excluding the output
- Auxiliary space excludes the buffered input and output.

## Edge cases

- Vertices are zero-based.
- Zero-weight edges are valid.
- The diagonal is explicitly zero.
- Output rows incrementally to avoid storing the entire matrix.

## Dry run

The sample maximum spanning tree uses edges `0-2` of weight three and `1-2` of weight two. The path from 0 to 1 has minimum edge two, improving on their direct edge of weight one.
