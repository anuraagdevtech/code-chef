# 556. Curry Stained Napkin

> CodeChef problem code [`F3`](https://www.codechef.com/problems/F3) &middot; difficulty **1815** &middot; time limit **0.5s**

| | |
|---|---|
| **Topic** | Graphs |
| **Technique** | Count mirrored copies of each original stained component |
| **Time** | $O(64+\log N)$ per test case |
| **Space** | $O(64)$ |
| **Roadmap course** | Rise from 3* to 4* (Level 4) |

## Question

The Chef has a huge square napkin of size 2^n X 2^n. He folds the napkin n-3 times. Each time he folds its bottom side over its top side, and then its right side over its left side. After each fold, the side length of the napkin is reduced by half. The Chef continues folding until there remains a 8x8 sheet, lying flat on a table.

Oh, did I forget to mention that the Chef was cooking a new brown colored curry while folding the napkin. He drops some brown colored gravy onto some cells in the folded 8x8 napkin. When he drops the gravy, it soaks through all the cells below it.

Now the Chef unfolds the napkin to its original size. There are now many curry stained brown colored cells in the napkin. They form several separate regions, each of which is connected. Could you help the Chef count how many regions of brown cells are there in the napkin?

Note that two cells are adjacent if they share a common edge (they are not considered adjacent if they only share a corner). Two cells are connected if we can go from one cell to the other via adjacent cells. A region is a maximal set of cells such that every two of its cells are connected.

Please see the example test case for more details.

**Input**

The first line contains t, the number of test cases (about 50). Then t test cases follow. Each test case has the following form:

- The first line contains N (3 ≤ N ≤ 10^9)

- Then, 8 lines follow. Each line is a string of 8 characters, 0 or 1, where 1 denotes a stained brown cell in the folded napkin.

**Output**

For each test case, print a single number that is the number of disconnected brown regions in the unfolded napkin. Since the result may be a very large number, you only need to print its remainder when dividing by 21945.

## Constraints

- About 50 test cases.
- 3 <= N <= 10^9.
- The folded pattern is exactly eight rows of eight binary characters.
- Output the number of regions modulo 21945.

## Approach

Flood-fill the stained components of the eight-by-eight pattern and record which of its four edges each component touches. Mirroring can join copies of the same original component, but cannot join different original components: every adjacency maps back to an adjacency in the original pattern.

After $k=N-3$ unfolds in each dimension, there are $m=2^k$ tiles per side. For one component, connections between horizontal tile copies form a line graph. Its $m-1$ seams alternate between the original right and left edges: $m/2$ right seams and $m/2-1$ left seams. Its number of horizontal groups is therefore $m-(m/2)R-(m/2-1)L$, where edge-touch flags are zero or one. The same formula with bottom and top gives the vertical groups.

The tile-copy graph is the Cartesian product of these two line graphs, so multiply their component counts and sum over the original components. Compute $m/2=2^{k-1}$ modulo 21945; no enormous integers are needed. With no unfolding, simply count the original components.

## Solution (Python)

```python
import sys


def main() -> None:
    tokens = iter(sys.stdin.buffer.read().split())
    out = []
    for _ in range(int(next(tokens))):
        n = int(next(tokens))
        grid = [next(tokens) for _ in range(8)]
        seen = set()
        components = []
        for r in range(8):
            for c in range(8):
                if grid[r][c] != 49 or (r,c) in seen:
                    continue
                flags = [False]*4
                seen.add((r,c))
                stack = [(r,c)]
                while stack:
                    rr,cc = stack.pop()
                    flags[0] |= cc == 0
                    flags[1] |= cc == 7
                    flags[2] |= rr == 0
                    flags[3] |= rr == 7
                    for x,y in ((rr-1,cc),(rr+1,cc),(rr,cc-1),(rr,cc+1)):
                        if 0 <= x < 8 and 0 <= y < 8 and grid[x][y] == 49 and (x,y) not in seen:
                            seen.add((x,y))
                            stack.append((x,y))
                components.append(flags)
        if n == 3:
            answer = len(components)
        else:
            half = pow(2,n-4,21945)
            m = 2*half
            answer = sum((m-half*right-(half-1)*left)*(m-half*bottom-(half-1)*top)
                         for left,right,top,bottom in components)%21945
        out.append(str(answer))
    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    main()
```

## Complexity

- **Time:** $O(64+\log N)$ per test case
- **Space:** $O(64)$
- Auxiliary space excludes the buffered input and output.

## Edge cases

- Diagonal stained cells are separate unless joined by side steps.
- Empty patterns return zero.
- An entirely stained sheet always has one component.
- Handle $N=3$ before evaluating $2^{N-4}$.

## Dry run

For a single interior stained cell and `N=4`, none of the four tile copies touch across seams, so there are four regions. If its component touches all four edges, every tile copy connects and only one region remains.
